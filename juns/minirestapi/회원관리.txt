📌 회원 관리 (User Management)
1. 회원 가입

중복된 log in Id는 등록 불가
비밀번호는 BCrypt로 암호화하여 저장
회원 가입 시 자동으로 "USER" 역할 부여
회원 가입 API는 인증 없이 접근 가능
2. 회원 삭제

인증된 사용자만 접근 가능
본인 계정 또는 ADMIN 역할만 삭제 가능 (선택사항)


📌 게시판 (Board)
1. 게시글 등록

인증된 사용자만 작성 가능
작성자 정보는 인증된 사용자 정보에서 자동으로 설정
제목과 내용은 필수 입력
2. 게시글 수정

인증된 사용자만 접근 가능
작성자 본인만 수정 가능
제목과 내용만 수정 가능 (작성자, 작성일은 변경 불가)
3. 게시글 삭제

인증된 사용자만 접근 가능
작성자 본인만 삭제 가능
게시글 삭제 시 관련 댓글도 함께 삭제 (CASCADE)
4. 게시글 목록 조회

인증된 사용자만 접근 가능
페이징 처리 (기본: page=0, size=10)
최신 글이 먼저 표시 (작성일 내림차순)
응답에 페이지 정보 포함 (총 페이지 수, 현재 페이지, 전체 데이터 수)
5. 게시글 상세 조회

인증된 사용자만 접근 가능
존재하지 않는 게시글 조회 시 404 에러 반환
작성자 정보 포함
📌 댓글 (Comment)
1. 댓글 등록

인증된 사용자만 작성 가능
작성자 정보는 인증된 사용자 정보에서 자동으로 설정
게시글이 존재하지 않으면 등록 불가
댓글 내용은 필수 입력
2. 댓글 목록 조회

인증된 사용자만 접근 가능
특정 게시글의 댓글만 조회 (postId 파라미터 필수)
삭제되지 않은 댓글만 조회 (del_yn = false)
작성일 오름차순 정렬
3. 댓글 삭제

인증된 사용자만 접근 가능
작성자 본인만 삭제 가능
소프트 삭제 방식 사용 (del_yn = true)
실제 데이터는 삭제하지 않음
📌 보안 요구사항 (Spring Security)
1. 인증 (Authentication)

HTTP Basic 인증 사용
회원 가입 API를 제외한 모든 API는 인증 필요
인증 실패 시 401 Unauthorized 반환
2. 권한 (Authorization)

모든 사용자는 기본적으로 "USER" 역할 보유
게시글/댓글 수정/삭제는 작성자 본인만 가능
권한이 없는 경우 403 Forbidden 반환
3. 비밀번호 암호화

BCryptPasswordEncoder 사용
회원 가입 시 평문 비밀번호를 암호화하여 저장
로그인 시 암호화된 비밀번호와 비교
