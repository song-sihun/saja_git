1. 주요 기능
- 회원 기능: 회원가입, 로그인, 로그아웃, 회원정보 수정, 회원 탈퇴
- 식당 기능: 식당 목록 조회, 이름/주소 검색, 상세 조회
- 관리자 기능: 식당 등록, 수정, 비활성화
- 예약 기능: 식당 선택, 예약 날짜/시간 선택, 인원 입력, 요청사항 입력, 내 예약 조회
- 권한 기능: 로그인 여부 확인, 관리자 권한 확인

2. 프로젝트 구조
- Domain: User, Restaurant, RestaurantTable, ReservationSlot, Reservation.
- Repository: DB 조회, 저장
- DTO: 화면 입력데이터, 응답 데이터
- Service: 회원가입, 로그인, 식당 관리, 예약 생성
- Controller: 화면 요청을 받고 Service를 호출
- Interceptor: 로그인 체크, 관리자 권한 체크

3. 흐름
- 로그인하지 않은 사용자는 로그인 화면으로 이동
- 사용자가 식당 상세 화면에서 예약 버튼을 누름
- 사용자는 예약 날짜, 시간 슬롯, 인원, 요청사항을 입력
- Service에서 식당 활성 상태, 슬롯 활성 상태, 과거 날짜 여부, 중복 예약 여부를 검사
- 예약 가능한 테이블 중 인원 수를 수용할 수 있는 가장 작은 테이블을 자동 배정
- 예약이 완료되면 내 예약 목록 화면으로 이동

4. 화면 순서
- 메인 화면 접속
- 회원가입
- 로그인
- 식당 목록 조회
- 식당 검색
- 식당 상세 화면 확인
- 예약 화면 이동
- 날짜, 시간, 인원 입력 후 예약
- 내 예약 목록 확인
- 관리자 계정으로 식당 등록/수정/비활성화 확인
